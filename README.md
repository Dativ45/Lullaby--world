# LULLABY WORLD

A bilingual (English/Persian), mobile-first lullaby discovery website.

## Safety and editorial principles
- No public chat, comments, direct messages, targeted advertising, or visitor accounts.
- No endless autoplay.
- Lullaby recordings are not included until composition and recording rights, provenance, attribution, and cultural context are checked.
- The collection cards are clearly marked as curation-in-progress placeholders.

## Deploy
This is a static site. GitHub Pages deployment is configured through the workflow in `.github/workflows/pages.yml`.
